# 20261118-010 Neural-guided symbolic search: PMNS observables from CKM angles and mass ratios

## Hypothesis

If a closed-form CKM/mass to PMNS relation exists, low-complexity expressions built from quark-sector and charged-lepton quantities that free phases cannot absorb (CKM angles, CKM phase, mass ratios) should predict a PMNS observable better than the same search does in fake universes. One real data point per target means any fit alone is meaningless; the only evidence is (i) a complexity budget, (ii) a grammar fixed before scoring, (iii) the fake-universe rate through the identical pipeline.

## Method

### Grammar (fixed before scoring; `symlib.py`)

- Variable leaves (16): θ12^q, θ13^q, θ23^q, δ^q (rad); r_uc = m_u/m_c, r_ct = m_c/m_t, r_ds = m_d/m_s, r_sb = m_s/m_b, r_em = m_e/m_μ, r_mt = m_μ/m_τ; and √ of the six ratios (q_uc ... q_mt).
- Constants (10): 1, 2, 3, 1/2, 1/3, √2, √3, π/4, π/2, π.
- Unary: neg, sqrt, sin, cos, asin, atan (no trig or inverse trig applied directly to a trig output, no neg(neg)). Binary: + − × ÷.
- Complexity = node count. The value is read as an angle: s_ij² = sin²(value), δ = value mod 2π. Complementarity forms (π/4 ± f) are in the grammar at +2 complexity.
- Functional dedup: every expression is evaluated at 8 random input points (fixed seed, fake-input prior); identical fingerprints are one function, the lowest-complexity one is kept. Distinct functions = trials count.

| complexity | raw candidates | new distinct functions | cumulative |
|---|---|---|---|
| 1 | 26 | 26 | 26 |
| 2 | 156 | 135 | 161 |
| 3 | 2,289 | 2,033 | 2,194 |
| 4 | 30,051 | 24,857 | 27,051 |
| 5 | 408,057 | 305,595 | 332,646 (18.3 bits) |
| 6 | 6,283,384 | 4,460,364 | 4,793,010 (22.2 bits) |

Validity rules (applied identically to real and fake universes): a mixing-angle expression must evaluate in [0, π/2], a δ expression in [−2π, 2π], and the propagated input error σ_pred must not exceed the NuFIT 1σ width of the target. These were added after the first pass, which was dominated by aliasing artefacts such as θ12 = (π/2)/r_uc = 795 rad (sin² of a huge angle is effectively random) and x / cos(π/2) (floating-point infinities with huge σ_pred). They are grammar-validity rules, not tuned on any pull; the first-pass output is superseded in `run.log`. Valid expressions at C ≤ 6: 2.16M (s12²), 1.68M (s13²), 2.27M (s23²), 4.10M (δ).

### Inputs and uncertainties

All inputs from `data/` via `src.rg.ckm_at` (CKM from PDG 2026, quark masses run with 4-loop QCD to M_Z, then SM RGEs to 2e16 GeV). The search runs at M_Z and repeated at 2e16 GeV (SM). The PMNS targets are always the NuFIT 6.1 low-scale values (SM PMNS running ≤ 0.12°, STATE.md; ignored).

Error sources: m_u, m_d, m_s, m_c, m_b, m_t, α_s(M_Z), CKM s12, s13, s23, δ. For each, the 1σ shift of all 10 base inputs is computed through the full `src.rg` chain (central differences, in-process monkeypatch of the loader, `src/` untouched; cached in `artifacts/exp010/real_inputs_*.json`). Resulting relative errors at M_Z: m_u/m_c 3.3%, m_c/m_t 1.5%, m_d/m_s 1.7%, m_s/m_b 0.9%, θ13^q 2.3%, θ23^q 1.8%, δ^q 2.2%; lepton ratios negligible. (PDG 2026 light-quark errors are smaller than the 5-10% assumed in the brief.) Each expression carries forward-mode tangents along the 11 source directions, so σ_pred² = Σ_sources (∂f/∂source · σ)² with correlations between ratios sharing a mass kept.

### Scoring (`symlib.ProfileScorer`)

One observable at a time, both orderings. The NuFIT 1D profile prof(t) is built from `src.data.pmns_delta_chi2(ordering, **{target: t})` (relative to the ordering's own minimum) and convolved with the prediction error by profiling the true value: Δχ²(p, σ_pred) = min_t [prof(t) + (t − p)²/σ_pred²]. For Gaussian profiles this is exactly the quadrature sum. Tabulated on a 2001 × 51 (p, σ) grid over the region prof < 64, exact at σ = 0, checked against the loader to < 0.004 in Δχ²; outside the region a Gaussian approximation is used (affects only |pull| > 8). pull = sign(p − best) √Δχ². The NO δ 1D profile never exceeds Δχ² = 1.03, so the NO δ target cannot discriminate anything.

### Neural guidance (`nn_guide.py`)

Synthetic universes: inputs from the fake-input prior, one target. Class 1 (50%): target generated by a planted tree from theory-motivated families (Clebsch-scaled angle or √mass ratio c·x with c ∈ {1, 1/2, 1/3, 2, 3, √2, √3} as × or ÷; π/4 ± c·x; asin/atan(c·x); c1·x1 ± c2·x2; asin(c1·x1 ± c2·x2); TBM/maximal/30° anchor ± c·x; δ = ±δ^q + kπ/2), NuFIT-sized noise added. Class 0: target from the Haar-induced distribution, independent of inputs. An MLP (3 × 256, SiLU, torch, 2 threads) maps 54 features of (inputs, target) to P(planted) and multi-hot probabilities of the leaves and ops in the generating tree. Guided search: keep the network's top-4 variable leaves, top-3 constants, top-3 unary and top-3 binary ops, enumerate that restricted grammar exhaustively to C = 7. Checks: (1) held-out AUC and leaf recovery; (2) on held-out planted universes with planted complexity ≥ 5, is the planted function in brute force C ≤ 6, in the NN-guided C ≤ 7 set, or in a random restriction of the same alphabet sizes; (3) on real data, P(planted) vs 300 fakes of each null kind, and what the guided set contains that brute force does not. PySR was not used: with one data row per target it has nothing to regress on, and the exhaustive enumeration already covers its search space at these complexities.

### Look-elsewhere nulls (`run_null.py`, `summarize_null.py`)

The identical pipeline (full grammar, all distinct expressions, same validity rules and scorers) on 300 fake universes per kind and scale. The nulls run to C ≤ 5 (332,646 functions); C = 6 was too slow for 4 × 300 fakes on the shared machine (≈30 s per universe). Real numbers in the null comparison are the C ≤ 5 values from the same pipeline.

- (a) real inputs, fake PMNS targets: Haar angles (`src.haar.sample_haar_angles`, fake i uses `default_rng([1001, i])`), Gaussian score with the NuFIT 1σ asymmetric widths of each ordering centred on the fake value, σ_pred in quadrature. Real comparison = the same Gaussian score centred on the NuFIT central values.
- (b) real PMNS targets with the NuFIT tables, fake inputs: Wolfenstein λ ~ U[0.10, 0.35], A ~ U[0.5, 1.2], ρ̄, η̄ ~ U[−0.5, 0.5] (exp 007 prior), mass ratios log-uniform over one decade centred on the real value at that scale; same relative input errors. Seeds `[2002, i]` (M_Z), `[2003, i]` (GUT).

Hit at complexity C: fake best |pull| (complexity ≤ C) ≤ real best |pull|. Also c1 = lowest complexity reaching |pull| < 1; hit if fake c1 ≤ real c1. Rates and 95% Clopper-Pearson CIs from `src.stats.fake_universe_rate`.

### Multi-observable templates (`templates.py`)

One function f(x) (one variable plus the 10 constants, full grammar, C ≤ 5: 29,704 distinct f) applied with one of 4 sector mappings fixed in advance: ckm (x_ij = θ_ij^q), down (√(m_d/m_s), √(m_d/m_b), √(m_s/m_b)), lepton (√(m_e/m_μ), √(m_e/m_τ), √(m_μ/m_τ)), up (√(m_u/m_c), √(m_u/m_t), √(m_c/m_t)) for (θ12, θ13, θ23). 118,816 templates (16.9 bits). Joint score = sum of the 1D profile Δχ² (input errors profiled) for all three angles and for each pair. Same two nulls with 300 fakes each (the C ≤ 6 version, 1.14M templates, was stopped for time).

Training: 150,000 synthetic universes (50% planted), 10 epochs; no real data in training. Held-out (20,000): AUC planted vs Haar = 0.79; the true variable leaves are all within the network's top 4 in 43% of planted cases.

|---|---|---|---|---|
| 5 | 14 | 14 | 2 | 0 |
| 6 | 7 | 7 | 3 | 0 |
| 7 | 12 | 2 | 2 | 0 |
| 8 | 7 | 1 | 0 | 0 |
| all | 40 | 24 | 7 | 0 |

The network carries real information (7/40 vs 0/40 for a same-size random alphabet), but with a ~20× smaller budget it recovers far fewer planted functions than brute force, and for planted complexity 7-8, where brute force cannot reach, it recovers 2/19, the same as brute force recovers through lower-complexity equivalent forms. It does not demonstrably find anything brute force with the same budget would miss.

Real data: the guided C ≤ 7 sets (95k-468k functions per target) add 73k-341k functions not in the brute-force set; 85-11,605 of them have |pull| < 1 per target, best new |pull| 0.0002-0.09, i.e. the same saturation as brute force. Nothing structurally new (top guided expressions in `nn_guided_top.csv`, e.g. θ12 = atan√(2√(m_d/m_s) − m_e/m_μ), are numerology of the same kind).

Network statistic P(planted) on real data vs 300 fakes per null (hit = fake P ≥ real P): s12² 0.48 (null a 51-52/300 = 17%, null b 8/300 = 2.7% [1.2, 5.2]% at GUT and 12/300 = 4.0% [2.1, 6.9]% at M_Z); s13² 0.66 (null a 25/300 = 8.3%, null b 46-52%); s23² 0.38-0.50 (13-76%); δ 0.34-0.39 (12-82%). Lowest rate 2.7% (one of 32 cells), none below 1%.

## Parameter / complexity accounting

- Single observable: N = 1 per expression; k = log2(# distinct functions at that complexity) bits of choice: 11.1 bits at C ≤ 3, 14.7 at C ≤ 4, 18.3 at C ≤ 5, 22.2 at C ≤ 6, plus 1 bit for scale and 1 for ordering if chosen. No single-observable expression can meet k ≤ N − 2.
- Templates: N = 2 or 3, k = 16.9 bits + 2 bits (subset) + 1 bit (scale). Fails k ≤ N − 2.
- NN-guided sets: alphabet chosen by a network trained only on synthetic data; trials = guided-set size (~1e5 functions per target, `nn_guided_top.csv`), on top of the brute-force set.

## Verdict

No candidate. Over 4.8M distinct closed-form expressions (C ≤ 6) in CKM angles, CKM phase and six mass ratios, every PMNS observable is matched within 1σ by thousands of expressions, and at every complexity level the real data are matched no better than in fake universes (300 Haar-target and 300 fake-input universes per scale; lowest rate in 160 cells 2.7%, none below 1%). Known relations (QLC, TBM, KMS θ13 = θ_C/√2, leptonic GST) are recovered at the expected complexity and pulls and are beaten by many numerological alternatives. The template search finds no f that works for all three angles; the best two-angle template (T1, GUT only, θ12 and θ13 from up-quark mass ratios) has a per-cell fake rate of 0.7-1.3% that becomes ~8% after the subset/scale choice. The neural scorer, trained only on synthetic planted-relation universes, beats a random alphabet on synthetic data but finds nothing that brute force with a larger budget misses, and its real-data score is not unusual against either null (lowest rate 2.7%).

## Notes for src (no bug affecting results)

- `src.rg` has no hook for perturbed quark-mass inputs, so `symlib._patched_yukawas` monkeypatches `rg._data.load_masses`, `rg.load_sm_inputs` and `rg.quark_masses_mz` in-process. Proposed: a `masses=` / `sm_inputs=` override on `quark_masses_mz` and `derived_yukawas_mz`.
- `src.data.pmns_delta_chi2` is per-point Python; dense 1D profiles take ~10 s per (target, ordering). Proposed: a public `pmns_profile_1d(ordering, tag, analysis)` returning the shifted 1D table.
- The NO δ 1D profile peaks at Δχ² = 1.03, so single-observable δ predictions in NO are untestable; any future δ test should use the 2D (s23², δ) table jointly.
