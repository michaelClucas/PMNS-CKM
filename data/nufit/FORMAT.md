# NuFIT 6.1 Delta chi^2 tables

Generated by `experiments/20261118-001-data-build/build_nufit.py` from the four NuFIT 6.1 release files (see `data/SOURCES.md`).

File name: `v61_<analysis>_<ordering>_<projection>.csv`

- analysis: `TBoff` = IC23 w/o SK-atm (program default), `TByes` = IC24 with SK-atm
- ordering: `NO` or `IO`
- projection: NuFIT section tag with `/` replaced by `-`. One tag = 1D profile, two tags = 2D projection.

Columns (header row in each file):

| column | meaning |
|---|---|
| `s12sq`, `s13sq`, `s23sq` | sin^2(theta_ij) |
| `dcp_deg` | delta_CP in degrees, grid -180 to 180 |
| `log10_dm21sq_eV2` | log10(Delta m^2_21 / eV^2) |
| `dm3l_sq_1e-3eV2` | Delta m^2_31 (NO) or Delta m^2_32 (IO) in 1e-3 eV^2 |
| `delta_chi2` | Delta chi^2 after minimizing over all parameters not shown |

Delta chi^2 is relative to the global minimum over both orderings, so IO tables have a floor equal to the ordering penalty (1.486 for TBoff, 5.908 for TByes). `src.data.pmns_delta_chi2` subtracts each table's own minimum.

Committed: every 1D profile for both analyses; every 2D projection for TBoff; the T23-DCP 2D projection for TByes. Total about 10 MB, largest file about 0.6 MB.
